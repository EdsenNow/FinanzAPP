# FinanzApp - Sistema de Gestión de Finanzas Personales

## 1. Nombre del Proyecto
**FinanzApp** - Aplicación Web para el Control y Gestión de Finanzas Personales.

---

## 2. Descripción Breve del Proyecto
FinanzApp es una aplicación web moderna e interactiva diseñada para ayudar a los usuarios a tomar el control de su economía personal. Permite registrar ingresos y gastos en tiempo real, categorizar movimientos, establecer presupuestos mensuales y visualizar análisis financieros claros y visuales.

---

## 3. Objetivo del Proyecto
Proporcionar una plataforma intuitiva, segura y accesible que facilite el seguimiento del flujo de dinero personal, fomentando hábitos de ahorro e inversión mediante el monitoreo constante de transacciones y presupuestos.

---

## 4. Herramientas Utilizadas
* **Frontend:** HTML5, CSS3 Vanilla (Design System con CSS Variables), JavaScript (ES6+ Modular).
* **Backend & Base de Datos:** Firebase Authentication, Cloud Firestore DB, Firebase Hosting.
* **Control de Versiones y Gestión:** Git, GitHub, GitHub Projects.
* **Herramientas de Desarrollo:** Visual Studio Code, Node.js, npm.

## 7. Forma en que se Organizará el Trabajo
El proyecto se gestionará utilizando metodologías ágiles a través de herramientas nativas de GitHub:
1. **GitHub Issues:** Registro y priorización de requerimientos, historias de usuario y tareas técnicas clasificadas con etiquetas (`labels`).
2. **GitHub Projects:** Uso de un tablero Kanban interactivo estructurado en 4 columnas principales:
   * **Pendiente** (To Do)
   * **En proceso** (In Progress)
   * **En revisión** (In Review)
   * **Completado** (Done)
3. **Flujo Git:** Registro ordenado de avances mediante commits con mensajes descriptivos siguiendo convenciones estándar (`docs:`, `structure:`, `feat:`).
