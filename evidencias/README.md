# 📸 Evidencias de Ejecución y Pruebas - FinanzApp

Esta carpeta está destinada al almacenamiento de capturas de pantalla, videos de demostración y registros de pruebas del proyecto.

## 📌 Estructura Sugerida de Evidencias
* `/capturas-tablero/`: Capturas del tablero de GitHub Projects y sus columnas.
* `/capturas-issues/`: Capturas de los GitHub Issues creados y sus etiquetas.
* `/capturas-app/`: Capturas del funcionamiento de la interfaz de FinanzApp.
